## Git commmit messages
- use Conventional Commits for commit messages. This will help with generating changelogs and versioning.
- Use the following format for commit messages:
  - `feat: add new feature`
  - `fix: fix a bug`
  - `docs: update documentation`
  - `style: improve code style`
  - `refactor: refactor code`
  - `test: add or update tests`
  - `chore: update build process or auxiliary tools`
- keep commit messages concise and descriptive. Avoid using vague messages like "update" or "fix". Instead, describe what was changed and why.

## Security guidelines
Never commit secrets or sensitive information to the repository. This includes API keys, passwords, and other credentials. Use environment variables or secret management tools to handle sensitive data securely.
